# Cinerama Privacy

Cinerama is a personal Plex client. It sends no advertising identifiers, usage
statistics or playback telemetry to a Cinerama analytics service; no analytics
endpoint is configured.

The app communicates with Plex and your enabled media servers for sign-in,
libraries, artwork, playback and watch-state synchronization. Optional Seerr
requests go to the companion server you configure. Explicit group playback
sessions may use Apple's Group Activities services. External links open only
when requested.

Authentication is held in Keychain. Preferences, caches, downloads and pending
offline watch-state synchronization remain on your device as described in the
product and offline guides. Plex and any companion service have their own data
handling policies. Never include authentication tokens or token-bearing URLs
in issue reports.
